# 网页 AI 智能导入使用说明

## 第一次使用

1. 打开网站右上导航中的“AI 设置”。
2. 选择“OpenAI 兼容接口”或“Anthropic Claude”。
3. 填写服务商 Base URL、模型名和 API Key。
4. 保存，点击“测试连接”。
5. 自动规则落账默认关闭。只有在理解规则作用后才建议开启。

## 导入账单

1. 打开“导入账单”，上传支付宝 CSV/ZIP 或微信 XLSX。
2. 配置了 AI 时，页面会解析账单并建立临时 AI 导入会话。
3. AI 先查看整批交易分布和唯一商户/商品组合，提出分类体系，再为各交易组映射分类。
4. 查看已有分类与拟新增分类。新增分类必须勾选批准。
5. 逐笔勾选要立即确认的分类。未勾选的建议会保留在待审核分类草案中。
6. 可在对话框中输入“把某商户归入某分类”等指令，AI 只更新本批次建议。
7. 若要长期复用，勾选对应交易的“保存”选项。只有最终确认的交易才会生成规则。
8. 确认导入后，交易写入原始流水表，分类操作由 Ledger Engine 完成。

## 自动落账规则

自动落账必须同时满足：

- 设置页已开启“允许已授权规则自动落账”；
- 交易命中唯一启用的用户分类规则；
- 目标分类节点已经存在；
- 规则没有冲突；
- 规则命中结果满足置信度阈值。

模型单独返回 99% 置信度，也不会自动修改账本。
